## Long description

**Hanna reads the web to you — beautifully.**

Select any text and hear it instantly. Or sit back and let Hanna read entire articles with word-by-word highlighting that follows along like karaoke.

**✨ Three ways to listen**

- **Speak** — highlight any text, right-click, done. Perfect for emails, docs, and paragraphs
- **Read Page** — one click reads the whole article top to bottom, skipping menus and ads
- **Smart extraction** — built-in reader mode finds the actual content on news sites, blogs, and newsletters

**🎤 Voices for every mood**

- 28 preset voices across professional, expressive, and character styles
- **Voice design** — describe any voice in words: "a warm Australian female with a soothing tone" and hear it come alive
- **Voice cloning** — upload a sample and let Hanna read in your own (or anyone's) voice
- Multiple providers: MiMo TTS, Fish Audio, and ElevenLabs — bring your own API key

**📖 Built for long reads**

- Word-by-word karaoke highlighting so you can follow along
- Auto-scroll keeps the current word centred
- Adjustable speed from 1× to 3× with natural pitch preservation
- Pause, resume, or stop anytime — click, button, or Escape
- Smart caching so re-reads are instant and don't cost extra API calls

**🔒 Private by design**

- No account, no analytics, no tracking
- Your API keys and settings never leave your browser
- Text goes directly to your chosen TTS provider — nothing passes through any server in between

**🚀 Getting started**

1. Install and click the Hanna icon
2. Choose a provider and paste your API key
3. Select some text, right-click, and hit **Hanna: Speak**

That's it. Free TTS models available (Fish Audio's s2.1-pro-free costs nothing).
